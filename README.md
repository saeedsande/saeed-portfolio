## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/saeedsande/saeed-portfolio.git
```

Navigate to the project folder:

```bash
cd saeed-portfolio
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
npm start
```
